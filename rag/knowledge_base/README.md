# ECHO-AI Knowledge Base

Original, general-audience notes written for ECHO-AI. They summarize widely
accepted, non-clinical wellbeing and study guidance in plain language.

- They are **not medical advice** and not a substitute for a professional.
- No third-party text is copied; there are no licensing restrictions beyond the repository license.
- Format: one `# Title` per file, one `## Section` per retrievable chunk.

To add a source: add a Markdown file in this format, keep claims general and
non-diagnostic, and note its origin here.
